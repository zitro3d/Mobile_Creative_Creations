Wondrous Grid — Help & Shortcuts

      
    

    

      
Getting Started

      

        Pick a canvas size from the Preset dropdown (or set custom dimensions),
        choose a color from the DLX Palette, and click cells in the paint grid.
        The code panel on the right updates with every pixel you paint. You can
        also edit the code directly and click Apply Edits to re-render.
      


      
Tools

      

        
P or BPaint tool (default)

        
IEyedropper — click a painted pixel to pick its color

        
X or EEraser (or right-click any time)

        
GFill bucket — click to flood-fill a connected region with the active color (right-click to erase a region)

        
RRectangle tool — drag to draw a filled rect. Shift = square. Right-click drag = erase rect.

        
OEllipse tool — drag to draw a filled ellipse. Shift = circle.

        
MSelection / marquee — drag to select a region (dashed "marching ants" outline)

        
+ / −Zoom in / out on the paint grid

        
FFit zoom to current pane size

        
XSwap to the previous active color (Photoshop-style fg / bg toggle)

        
Shift + clickDraw a straight line from the last painted pixel to the click (Bresenham line tool, in paint mode)

      


      
Paint Helpers

      

        Symmetry (⫯ Sym button) — cycles off → vertical mirror → horizontal mirror → both axes.
        While on, each paint stroke is auto-mirrored across the selected axis (yellow guide lines show where the mirror axes are).
      

      

        Lock α (🔒 Lock α button) — when on, paint operations only affect cells that already have a pixel. Useful for recoloring shapes without redrawing the silhouette.
      

      

        Snap to palette (button next to "DLX Palette" header) — for every painted pixel, snaps its color to the nearest DLX palette swatch (TSC ∪ PXC ∪ your custom colors). Useful after importing a PNG that has off-palette pixels from anti-aliasing.
      


      
Selection & Clipboard

      

        Pick the selection tool (M) and drag a rectangle to select cells.
        The marquee animates as a dashed "marching ants" outline. Then:
      

      

        
Cmd/Ctrl + ASelect all (switches to selection tool)

        
Cmd/Ctrl + CCopy the selected pixels to an internal clipboard

        
Cmd/Ctrl + XCut (copy + clear)

        
Cmd/Ctrl + VPaste at the current selection's top-left (or 0,0 if no selection)

        
Delete / BackspaceClear all pixels inside the selection

        
EscDeselect (or close an open modal)

      

      

        Clipboard is internal to Wondrous Grid — copy a sprite-region from one frame, switch to another frame, paste. Survives until overwritten or page refresh.
      


      
Canvas Navigation (Pro)

      

        
Mouse wheelZoom in / out — zooms toward the cursor (cell under cursor stays in place)

        
Hold Space + dragPan the canvas. Cursor becomes the grab hand. Aseprite / Photoshop convention.

        
Middle-mouse dragPan the canvas (no modifier needed)

        
Cmd/Ctrl + 0Fit zoom to pane (same as F)

        
Cmd/Ctrl + 1Default 12× zoom ("actual size"-ish for pixel art)

      

      
A brief Space tap with no drag still toggles animation play / pause — only HELD Space-with-drag enters pan mode.


      
Animation Timeline

      

        The strip at the bottom holds one or more frames. Each frame is a
        separate pixel map with its own duration. Click any thumbnail to switch frames
        for editing. The active frame gets a yellow ring with a soft glow.
      

      

        
SpacePlay / pause animation

        
← / →Previous / next frame

        
Alt + DDuplicate current frame (also: click the + thumbnail at the end of the strip)

        
Alt + NAdd new blank frame (toolbar "+ Blank")

        
Alt + DeleteDelete current frame (confirms)

      

      

        Drag any thumbnail onto another to reorder frames. Dragging the active
        frame keeps it active in its new position.
      

      

        Onion skin shows the previous (◀ prev) and / or next (next ▶)
        frame faintly under the one you're editing — useful for animating smooth motion.
        Duration (ms) is per-frame. The ≈ N FPS readout next to the duration
        input is the frame-rate equivalent (1000 / duration ms).
      

      

        Code output: the code panel shows the current frame only so Apply
        Edits has a clear target. ⎘ Copy Code in the header emits the whole
        sprite — a list of px() calls for single-frame sprites, or a full
        drawSprite(ctx, gameFrame) function with a switch-case across
        frames for animated sprites.
      


      
Code Panel

      

        Click any line in the code panel that's a px() call — the matching
        pixel gets a pulsing yellow ring on the canvas. Lets you trace code lines back
        to the pixel they draw without hunting visually.
      

      

        
Cmd/Ctrl + EnterApply Edits — re-render grid from the current code panel text (same as clicking the orange button)

      


      
Layout

      

        Three column splitters + one row splitter, all drag-resizable, all double-
        click-resettable:
      

      
    
        
  • Between the Color panel and the paint grid (horizontal)
    • 
        
  • Between the paint grid and the Code panel (horizontal)
    • 
        
  • Between the main area and the Timeline (vertical — drag up to grow the timeline)
    • 
      

      

        Sizes persist across sessions in browser storage.
      


      
Canvas Transforms

      

        
Shift + HFlip horizontal (mirror left/right)

        
Shift + VFlip vertical (mirror top/bottom)

        
Shift + RRotate 90° clockwise (swaps width × height)

      

      
All transforms are one undo step — Cmd/Ctrl+Z reverts.


      
Edit

      

        
Cmd/Ctrl + ZUndo last action (up to 50 steps back)

        
Cmd/Ctrl + Shift + Z or Cmd/Ctrl + YRedo

      

      
Each paint stroke (one mousedown→mouseup) counts as one undo step. Loading a sprite, importing a PNG, or resizing the canvas wipes the undo history.


      
File

      

        
Cmd/Ctrl + SSave current sprite as JSON file

        
Cmd/Ctrl + OOpen JSON file

        
Cmd/Ctrl + Shift + SSave current as new asset in My Assets

        
Cmd/Ctrl + CCopy generated code to clipboard (when not focused in a text field)

        
Cmd/Ctrl + LOpen the Assets library / Manage panel

        
? or HOpen this help

        
EscClose any open modal

      


      
Reference Layer

      

        Load a PNG/JPG underneath the grid as a tracing template. Adjustable opacity,
        toggleable visibility, scales to match the canvas. Auto-downscales large
        images so localStorage doesn't fill up.
      


      
Assets

      

        Two sources in one dropdown:
      

      
    
        
  • Game Sprites — the live in-game artwork (rig, gunship variants, harpooner). Read-only; picking one loads a fresh copy.
    • 
        
  • My Assets — your personal library, stored in this browser (IndexedDB). Save sprites here for fast re-opening.
    • 
      

      

        Also from the same dropdown: Import PNG from file, Save Current as New Asset, Manage My Assets (rename / duplicate / export / delete).
      


      
Sharing With Others

      

        My Assets lives in YOUR browser only. To share a sprite, click 💾 Save JSON
        and send the file. The recipient can 📂 Load JSON to open it.
      


      
Tips

      
    
        
  • Drag the thin bars between panels to resize them. Double-click a bar to reset.
    • 
        
  • The code panel writes one px(ctx, '#hex', x, y, 1, 1) per pixel — edit freely.
    • 
        
  • Custom colors used in a sprite are listed in the code comment header so they can be wired into the game's TSC / PXC master palettes.
    • 
        
  • Everything autosaves to the browser. Refresh-safe.
    •

        Welcome to Wondrous Grid
      

      
    

    

      
You're inside a pro pixel-art editor. If you know Photoshop or Aseprite, you'll feel at home. Quick orientation:

      
    
        
  • Center canvas — paint here. Right-click erases without switching tools. Scroll to zoom toward the cursor; hold Space to pan.
    • 
        
  • Left panel — drawing tools (B/E/I/G/R/O/M), then the active color, palette, layers, and a mini-map.
    • 
        
  • Right panel — the generated code, live. Edit and click Apply Edits to re-render.
    • 
        
  • Bottom strip — animation frames. Click a thumb to switch, drag to reorder, "+" to duplicate to the end.
    • 
        
  • Tags — name a frame range (walk / idle / etc.) and play it independently.
    • 
        
  • Layers — stack with visibility + opacity. Active layer receives all paint strokes.
    •
