Wondrous Grid — Help & Shortcuts

Getting Started

Pick a canvas size from the Preset dropdown (or set custom dimensions), choose a color from the DLX Palette, and click cells in the paint grid. The code panel on the right updates with every pixel you paint. You can also edit the code directly and click Apply Edits to re-render.

Tools

P or BPaint tool (default)
IEyedropper — click a painted pixel to pick its color
X or EEraser (or right-click any time)
GFill bucket — click to flood-fill a connected region with the active color (right-click to erase a region)
+ / −Zoom in / out on the paint grid
FFit zoom to current pane size

Animation Timeline

The strip at the bottom of the window holds one or more frames. Each frame is a separate pixel map with its own duration. Click any frame thumbnail to switch to it for editing. Use the timeline toolbar (or shortcuts below) to add / duplicate / delete frames, set frame timing, and play the animation.

SpacePlay / pause animation
← / →Previous / next frame
Alt + NAdd new blank frame
Alt + DDuplicate current frame
Alt + DeleteDelete current frame (confirms)

Onion skin checkboxes show the previous (◀ onion) and / or next (onion ▶) frame faintly under the current one — useful for animating smooth movement. Duration (ms) is per-frame.

Code output: the code panel always shows the current frame only (so Apply Edits has a clear target). ⎘ Copy Code in the header emits the whole sprite — a list of px() calls for single-frame sprites, or a drawSprite(ctx, gameFrame) function with a switch-case across all frames for animated sprites.

Canvas Transforms

Shift + HFlip horizontal (mirror left/right)
Shift + VFlip vertical (mirror top/bottom)
Shift + RRotate 90° clockwise (swaps width × height)

All transforms are one undo step — Cmd/Ctrl+Z reverts.

Edit

Cmd/Ctrl + ZUndo last action (up to 50 steps back)
Cmd/Ctrl + Shift + Z or Cmd/Ctrl + YRedo

Each paint stroke (one mousedown→mouseup) counts as one undo step. Loading a sprite, importing a PNG, or resizing the canvas wipes the undo history.

File

Cmd/Ctrl + SSave current sprite as JSON file
Cmd/Ctrl + OOpen JSON file
Cmd/Ctrl + Shift + SSave current as new asset in My Assets
Cmd/Ctrl + CCopy generated code to clipboard (when not focused in a text field)
Cmd/Ctrl + LOpen the Assets library / Manage panel
? or HOpen this help
EscClose any open modal

Reference Layer

Load a PNG/JPG underneath the grid as a tracing template. Adjustable opacity, toggleable visibility, scales to match the canvas. Auto-downscales large images so localStorage doesn't fill up.

Assets

Two sources in one dropdown:

  • Game Sprites — the live in-game artwork (rig, gunship variants, harpooner). Read-only; picking one loads a fresh copy.
  • My Assets — your personal library, stored in this browser (IndexedDB). Save sprites here for fast re-opening.

Also from the same dropdown: Import PNG from file, Save Current as New Asset, Manage My Assets (rename / duplicate / export / delete).

Sharing With Others

My Assets lives in YOUR browser only. To share a sprite, click 💾 Save JSON and send the file. The recipient can 📂 Load JSON to open it.

Tips

  • Drag the thin bars between panels to resize them. Double-click a bar to reset.
  • The code panel writes one px(ctx, '#hex', x, y, 1, 1) per pixel — edit freely.
  • Custom colors used in a sprite are listed in the code comment header so they can be wired into the game's TSC / PXC master palettes.
  • Everything autosaves to the browser. Refresh-safe.
