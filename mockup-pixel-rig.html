WHAT'S IN THIS MOCKUP

  • Rig drawn with 30+ fillRect calls — cyan hull, lighter highlight band, darker shadow band, yellow caution stripe, rust damage decals, cabin armor with dark visor, antenna fin, side-vent engine pod with cyan glow.
  • Cargo is a dark crate with yellow contents visible through an opening + corner rivets — separate sprite so it can be stolen/swapped/lost in game.
  • Chain drawn as 6 cyan energy-link beads with a glowing connector line + per-link pulse animation phased so it reads as energy flowing rig→cargo.
  • Flame three-layer downward jet (deep-blue outer, light-cyan mid, white-hot core), each layer flickers independently per-frame with sine offsets so it never reads as a static image.
