THE CANDY-CRUSH-FOR-DELIVERY STRATEGY

King turned a single match-3 into a portfolio. Each Candy Crush game targets a slightly different mood / session length / mechanic preference, but they all live in one universe and cross-promote each other. The same model fits DLX shockingly well: every game is a different job in the Dumplord X-Press world. Action arcade, daily ritual, retro runner, route puzzle, physics sim — all set in the same 2052 wasteland with the same brand voice.

How to actually get there

  • Phase 1 (now): polish HAULER. Don't ship sister apps until the flagship is loved.
  • Phase 2: ship DLX FREIGHT as the daily-ritual sister. Reuses 80% of HAULER's engine — different framing, different feel, low cost.
  • Phase 3: evaluate one concept tile per quarter. Don't build all eight at once. Ship the one that's easiest to test and most distinct from what you already have. DLX PAPER (retro runner) is a strong third candidate — totally different mechanic but instantly readable.
  • Brand glue: shared DLX badge, shared trucker/dispatcher voice, shared currency (🔩 SCRAP) and shared Garage of rigs that work across games. That's the glue Candy Crush has too — same cast, same currency, same world, different rules.

WHY THE TWO APPS WORK AS A PAIR

DLX HAULER — chaos / arcade / orange

  • Identity: the messy, loud, action-game half — flap, dodge, grab loot, stack combos.
  • Loop: 50-level campaign, beat one to unlock the next. Star hunt for replays.
  • Visual: high-contrast orange/red, dramatic art panels, big chunky CTA.
  • Career: ROUTES · STARS · SCRAP. Garage of rigs.
  • Session: 5–15 minute play burst.

DLX FREIGHT — logistics / shipping / blue+gold

  • Identity: the methodical, ritualistic half — one route a day, manifest, par time, streak.
  • Loop: show up daily, deliver today's load, keep your streak alive. 20-route rotation.
  • Visual: deep navy + gold, dispatch-board chrome, manifest list, route diagram (origin → drop), week-dot streak grid.
  • Career: DELIVERED · ON-TIME % · EARNED $. Different rig (the RELAY — purpose-built for shipping vs the HAULER's all-purpose chaos).
  • Session: 2–5 minute daily ritual.

The split earns

  • Each app gets a clean elevator pitch — no more "what is this app?" confusion.
  • App-store discovery doubles. Sister-brand cross-linking ("Also by DUMPLORD X-PRESS") is the unification.
  • Each can evolve independently — a Freight v2 with leaderboards doesn't have to wait for a Hauler v2.
  • Players who only want one ritual can have it without the other's pressure.

The split costs

  • Career progression doesn't carry across (unless you build a shared backend for rigs / scrap / badges).
  • Two PWAs to maintain — service workers, build versions, deploy steps, asset hosting.
  • Players stuck on "what's the difference?" if marketing isn't sharp.
