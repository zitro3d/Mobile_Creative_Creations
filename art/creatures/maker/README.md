# The Maker — Aurora Engine Boss (final boss)

Status: design brief only. Boss spawn / draw / fight is **not yet
implemented in code** — currently aurora plays as endless past
score 670 with sentinel-9999 for the gold medal.

## Role
- **Final boss** of the campaign, appearing in THE AURORA ENGINE
  (Level 10) once the player reaches the boss trigger score
  (~600 in current LEVEL_GAPS).
- A teleporting cosmic specter, *not* a chase-and-charge boss like
  earlier bosses. It phases in/out of the void rather than flying
  toward the player.
- Defeating it sets the run score to >= 9999 (sentinel) so the gold
  medal locks in. See `MEDAL_THRESHOLDS[9]`.

## Visual direction
- **Silhouette**: a robed/winged figure made of brass plating and
  star-stitched fabric. Reads as an "engine cult" priest — the one
  who built (or is) THE AURORA ENGINE.
- **Color**: brand brass (`#ffd060`, `#ffe28a`, `#ffd83d`) accents
  over deep violet/cosmic-black hull (`#04020c`, `#1c0838`,
  `#46286a`).
- **Glow**: soft magenta-cyan halo around the silhouette, sampled
  from the aurora ribbon palette so the boss feels born of the
  level, not pasted in.
- Pixel-pixel anatomy: a tall pylon-like body with two outstretched
  arm sweeps that mirror the in-game engine monolith rings (the
  monoliths in the horizon are essentially smaller siblings of the
  boss).
