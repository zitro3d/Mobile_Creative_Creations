DLX GARBAGE HAULER — MASTER PALETTE
====================================
Every sprite stays inside these colors. Need a new shade? Send it
over with what it's for — we'll wire it in. Tight palette = the
game stays visually coherent.

The .gpl version lives in the same folder. Import it via
Aseprite → Palette → Presets → Load.
